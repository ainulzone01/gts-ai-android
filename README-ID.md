# GTS AI Android v4

Project Android WebView untuk GTS AI versi web terbaru.

## Fitur
- Tampilan GTS AI hitam/emas dengan logo Bitcoin.
- Login/daftar Supabase.
- Dashboard, Paket, Bonus, Saya.
- Deposit + upload bukti.
- Withdrawal.
- Approval admin.
- Data online melalui Supabase.
- Pemilihan bukti gambar dari galeri Android.

## Cara membuat APK
1. Install Android Studio versi terbaru.
2. Open folder `gts-ai-android-v4`.
3. Tunggu Gradle Sync selesai.
4. Pilih `Build > Build App Bundle(s) / APK(s) > Build APK(s)`.
5. APK debug biasanya berada di `app/build/outputs/apk/debug/app-debug.apk`.

Catatan: aplikasi ini membungkus versi sandbox/demo GTS AI dan tidak mengubahnya menjadi sistem investasi uang nyata atau keuntungan yang dijamin.
